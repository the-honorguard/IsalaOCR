# IsalaOCR 3.11.7 — Fullscreen Panel Viewer

Panel Setup now has a large focus editor for positioning project-wide table search regions.

- **Volledig scherm** expands the existing editor instead of opening a second copy.
- The source image is aspect-correct and scaled to the largest available viewport size.
- Panel selection, draw, Paddle snap, save and source navigation live in a floating toolbox.
- The project panel list can be shown or hidden as a floating overlay.
- Previous/next source controls make it practical to validate the same panel profile against multiple representative screenshots.
- Unsaved changes are protected before navigating to another source.
- `F` toggles focus mode; `Esc` leaves it.
