# IsalaOCR 3.11.10

Hotfix for the Table Cell Reviewer reconstruction proposals.

- The yellow dashed reconstruction proposal and its `+` button are now reliably clickable.
- Pointer events on reconstruction proposals no longer start the canvas marquee selector.
- Reconstruction proposals are layered above ordinary candidate boxes.
- Clicking a proposal shows explicit progress, success, or API error feedback.
- The accepted proposal becomes a positive manual cell immediately in the current reviewer.
