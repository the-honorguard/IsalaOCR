# IsalaOCR 3.8.11 — Detection Studio feedback and zoom

## Review action feedback

Review mutations now immediately show a busy indicator with a spinner and the number of crops being processed. Mutating controls are disabled until the request completes, preventing accidental duplicate submissions. Success and failure remain visible in the review status message.

## Zoomable source viewer

The source canvas now lives in a scrollable viewport. Use Fit, +/−, 1:1, Focus selection and fullscreen controls, or the mouse wheel to zoom. Hold Space and drag (or use the middle mouse button) to pan while zoomed. Crop overlays, marquee selection and geometry editing continue to use original source-image coordinates.

This is an application/UI release; training image versioning is unchanged.
