# IsalaOCR 3.11.8 — Fullscreen Table Cell Reviewer

- Table Cell Review Studio now has the same viewport-filling focus workflow as Panel Setup.
- The full review canvas occupies the viewport while existing review state, selection, Smart Fit and resize handles stay intact.
- Review controls become a floating toolbox in fullscreen/focus mode.
- Zoom/view controls remain available as a separate compact floating toolbox.
- Candidate/inspector panels can be shown as a floating right-side overlay instead of permanently consuming canvas width.
- Previous/next source controls allow rapid validation across representative images.
- F toggles reviewer fullscreen; Alt+Left/Alt+Right switches source; Esc leaves edit mode first and then closes focus mode.
- Source navigation warns when a candidate is still in unsaved geometry edit mode.
