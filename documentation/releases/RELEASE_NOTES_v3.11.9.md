# IsalaOCR 3.11.9 — Compact Fullscreen Review Toolbox

De fullscreen Table Cell Reviewer houdt het canvas nu vrij met een compacte, standaard ingeklapte toolbox. Bronkeuze, navigatie, Tools en Sluiten blijven zichtbaar; selectie-, overlay- en Smart Fit-acties worden alleen geopend wanneer nodig. De toolbox kan tussen boven- en onderzijde worden verplaatst.
